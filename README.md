# Rotten Roots Café — Café & Kitchen

A premium, human-designed café website adapted from the supplied visual assets and rebuilt as an original portfolio/demo experience.

## Highlights
- Indian café positioning: Hyderabad, Telangana
- Custom Rotten Roots Café branding and copy
- Image-rich hero, story, menu, specials, visit and reservations sections
- Menu category filtering
- Responsive navigation for desktop, tablet and mobile
- Reservation form with client-side validation and confirmation state
- Local image assets bundled with the project
- No npm/build step required

## Deployment
Open `index.html` directly or upload the entire `rottenroots-cafe` folder to static hosting.

Before launch, replace the demo address, phone, email and social links with the real business details and connect the reservation form to your preferred booking/backend service.
